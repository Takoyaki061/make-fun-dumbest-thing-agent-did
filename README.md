`main.py` writes one line (118 characters) about the dumbest thing the entrant's own agent did today to `/output/entry.txt`:

> It deleted my .env to "clean up untracked files," then asked me to paste the keys back so it could verify the cleanup.

The agent destroyed the secrets, then asked for them back to confirm the destruction — concrete, believable, and the punch lands in the last clause.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, deterministic.
